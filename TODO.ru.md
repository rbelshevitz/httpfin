# План httpfin после версии 0.2

Основной рабочий путь версии 0.2 готов: сбор наблюдений, JSON API, текстовый
отчёт, HTML status-page, TLS/HTTP-режимы, Docker smoke-сценарий и документация.

## Ближайшие приоритеты

### Высокий

- [ ] Провести нагрузочное тестирование Nginx-модуля и пути через
  Unix-датаграммы: пропускная способность, переполнение, остановленный или
  медленный сборщик, восстановление и влияние на задержку запросов.
  Container smoke уже проверяет ограниченную нагрузку, остановленный сборщик и
  восстановление хранения; полноценное stress-тестирование и характеристика
  переполнения ещё впереди.
- [ ] Добавить семантическое сравнение двух сохранённых отчётов. Сравнивать
  нормализованные наблюдения, а не HTML/TXT: клиентов, User-Agent, профиль,
  TLS, ALPN, SNI, статус, время, размер ответа и точку наблюдения. Добавить
  контрактные тесты отчёта для `go-http`, `go-tls`, `nginx-http-module` и
  отсутствующих полей.

### Средний

- [ ] Добавить метрики коллектора для Prometheus: `received`, `decoded`,
  `stored`, `dropped`, ошибки handoff, число записей в store, uptime и состояние
  ingest.

### Перспективный

- [ ] Спроектировать и реализовать отдельный wire observer для raw ClientHello,
  стандартных JA3/JA4 и признаков HTTP/2 на уровне соединения. Не смешивать его
  с путём Nginx HTTP-модуля.

## Сознательно отложено

SQLite или другое постоянное хранилище истории, автоматическое обновление
профилей и распределённое хранилище не входят в ближайший план. Возвращаться к
ним стоит только при появлении конкретной эксплуатационной потребности.

## Текущие ограничения

- Nginx HTTP-модуль работает после TLS termination и не видит исходный
  ClientHello или HTTP внутри TLS passthrough.
- Unix datagram работает в режиме best effort: событие может потеряться, а
  запрос клиента всё равно будет обслужен.
- User-Agent, профиль и fingerprint можно подделать; это не доказательство
  личности клиента.
- `Risk` — метка источника, а не вычисленная оценка угрозы.
- `Baseline` — ограниченное сравнение `ClientHelloSig`, а не вердикт о клиенте.
- Динамический модуль Nginx должен соответствовать версии Nginx и libc.
