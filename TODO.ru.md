# План httpfin

## Граница продукта

`httpfin` — диагностический наблюдатель перед API. В поддерживаемой production-
схеме Nginx завершает TLS, а модуль отправляет ограниченное HTTP-событие в Go.
Go хранит последние наблюдения и строит понятный отчёт.

Продукт не аутентифицирует клиентов, не блокирует трафик и не является MITM-
прокси. В пути HTTP-модуля Nginx он не выдаёт стандартные JA3/JA4.

## Ограничения текущей версии

- HTTP-модуль Nginx работает после завершения TLS и не может разобрать исходный
  ClientHello или увидеть HTTP внутри passthrough.
- Unix datagram быстро и неблокирующе передаёт события. Событие может потеряться,
  а запрос клиента всё равно завершится; access log остаётся записью запроса.
- Динамический модуль должен быть собран под ту же версию Nginx и ту же libc.
