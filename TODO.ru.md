# План после версии 0.2

Версия 0.2 закрывает основной рабочий сценарий: сбор наблюдений, JSON API,
текстовый отчёт, HTML status-page, TLS/HTTP-режимы и документацию. Ниже
остались только точечные доработки эксплуатационной надёжности и точности.

## Граница продукта

`httpfin` — диагностический наблюдатель перед API. Он показывает только то,
что было собрано в конкретной точке наблюдения. Он не устанавливает личность
клиента, не аутентифицирует его и не блокирует запросы.

Поддерживаемые точки наблюдения:

- `go-http` — HTTP middleware: HTTP-запрос и ответ, без ClientHello;
- `go-tls` — прямой TLS listener на Go: TLS version, SNI, ALPN и собственная
  `ClientHelloSig`;
- `nginx-http-module` — ограниченное HTTP-событие после TLS termination.

Встроенные пути пока не вычисляют стандартные JA3, JA4 и HTTP/2 fingerprints.
Пустое поле означает «не наблюдалось в этой точке».

- [x] JSON API, текстовый отчёт и HTML status-page на общей модели

- [x] Таблица наблюдений: время, IP, метод, путь, HTTP, задержка, профиль,
  TLS/ALPN, SNI, UA и точка детектирования.
- [x] Детали записи с Client, TLS, доступными fingerprint-полями и baseline.
- [x] Baseline только для доступного `ClientHelloSig`.
- [x] Фиктивный `Risk` убран из status-page; поле исходной модели сохранено для

- [x] Время отображается в часовом поясе хоста через `time.Local`, а хранится в

## Отложено

Проверка переполнения Unix datagram, прав socket и поведения при остановленном
или медленном сборщике; отдельный wire-observer для настоящих JA3/JA4;
проверка `HTTP2Fingerprints` в baseline; SQLite-история; автоматическое
обновление профилей и распределённое хранилище. Эти задачи не входят в текущий
релиз и будут возвращены в план только при появлении конкретной потребности.

## Ограничения

- Nginx HTTP-модуль работает после TLS termination и не видит исходный
  ClientHello или HTTP внутри TLS passthrough.
- Unix datagram работает в режиме best effort: событие может потеряться, а
  запрос клиента всё равно будет обслужен.
- User-Agent, профиль и fingerprint — изменяемые сигналы, а не доказательство
  личности клиента.
- `Risk` — метка источника, а не вычисленная оценка угрозы.
- `Baseline` — ограниченное сравнение `ClientHelloSig`, а не вердикт о клиенте.
- Динамический модуль Nginx должен соответствовать версии Nginx и libc.
