# Семантика полей наблюдения

Используйте этот справочник, чтобы понять смысл каждого поля записи `httpfin` и
его источник. Транспортные и HTTP-поля описывают то, что получила точка
наблюдения; эвристические поля — классификацию по доступным данным.

## Risk

В текущей версии `Risk` не является вычисленной оценкой угрозы и не определяет,
нужно ли блокировать запрос.

Встроенные источники записывают техническую метку источника:

| Источник | Текущее значение |
| --- | --- |
| `go-http` | `Info` |
| `go-tls` | `Low` |
| `nginx-http-module` | `Info` |

`Review` и `High` могут прийти от внешнего сборщика. httpfin не объясняет и не
проверяет такую оценку.

Поэтому `Risk` не показывается в status page и не используется для выводов,
фильтрации или алертов. Поле сохраняется в исходном JSON для совместимости с
внешними источниками.

## Baseline

`Baseline` — не общий «рейтинг клиента». Это результат ограниченного сравнения
наблюдаемого `ClientHelloSig` с настроенным файлом baseline.

Проверка возможна только когда одновременно:

1. baseline загружен через `httpfin_baseline_file`;
2. точка наблюдения получила `ClientHelloSig`;
3. сигнатура сравнивается с `client_hello_signatures` профилей baseline.

Результаты:

- `matched` — сигнатура найдена и её профиль согласуется с обнаруженным
  профилем клиента;
- `mismatch` — сигнатура найдена, но профиль не согласуется;
- `unknown` — `ClientHelloSig` есть, но её нет в baseline;
- `—` — baseline отключён или ClientHello недоступен.

Сейчас baseline сравнивает только `ClientHelloSig`. Поле
`HTTP2Fingerprints` в конфигурации baseline пока не участвует в сравнении.

Baseline не доказывает, что клиент безопасен или вредоносен. Это повод открыть
детали записи и сопоставить UA, профиль, TLS, точку наблюдения и запрос.

## Что считается наблюдаемым признаком

- HTTP method, URL, status, elapsed и bytes — данные access-наблюдения;
- `User-Agent` — заявлен клиентом и легко изменяется;
- `detected_profile` — эвристика по доступным признакам, обычно по UA;
- TLS version, negotiated/offered ALPN, SNI и `ClientHelloSig` — транспортные
  признаки, доступные только в соответствующей точке наблюдения;
- `JA3`, `JA4` и `HTTP2Fingerprint` — отдельные поля модели, но встроенные
  production-пути httpfin сейчас их не вычисляют;
- `observation_point` — источник, который реально создал запись.

Транспортные признаки труднее изменить через обычный HTTP-заголовок, но их всё
равно может сформировать клиент, прокси или TLS-impersonation. Это наблюдаемые
сигналы, а не неизменяемый идентификатор.
