# Аудит безопасности и надёжности

Это инженерная проверка текущей реализации, а не формальная сертификация.
Пункты с приоритетом P0 нужно закрыть до публикации прямого listener или Unix
socket в недоверенной среде.

## Результаты

### P0 — возможное повреждение памяти в Nginx worker — исправлено в рабочем дереве

`nginx-module/ngx_http_httpfin_module.c` собирает JSON размером 4096 байт через
непроверяемые `ngx_cpymem()`. Функция сериализации строки может остановиться у
границы буфера, но вызывающий код не узнаёт об усечении и продолжает записывать
префиксы полей и закрывающий suffix. Длинные URI, Host или User-Agent могут
записать данные за пределами stack buffer и уронить worker.

Теперь используется bounded builder: он проверяет каждую операцию и возвращает
`oversize` до выхода за границу. Сборка Nginx 1.28.3 из исходников и container
smoke test для закреплённого Alpine 3.23 прошли.

### P0/P1 — неограниченная map ClientHello — исправлено в рабочем дереве

`internal/tlsinspect.Observer` сохраняет Hello для каждого ClientHello и удаляет
запись только после HTTP-запроса. Оборванные handshakes остаются в map. Поток
незавершённых handshakes может бесконечно увеличивать память.

Добавлены TTL, жёсткий лимит и удаление устаревших записей. Очистка строго по
событию закрытия соединения ограничена возможностями Go TLS callback API.

### P1 — нет таймаутов HTTP/TLS — исправлено в рабочем дереве

Оба Go-сервера запускаются без read/write/header/idle timeout и ограничения
размера headers. Медленный клиент может надолго удерживать goroutine и sockets.

Оба listener теперь используют read, write, header, idle timeout и
`MaxHeaderBytes`.

### P1 — spoofing событий через Unix socket — снижено

Socket получает права `0660`, поддерживает явную группу через
`httpfin_socket_group`, а ingest отклоняет неизвестную версию события и слишком
длинные поля. Runtime-каталог должен быть доступен только группе worker Nginx;
любой участник этой группы всё ещё может подделать событие — это ожидаемое
ограничение локальной интеграции.

### P1 — reconnect после перезапуска Go — исправлено в рабочем дереве

Модуль повторяет подключение при следующем запросе, если collector недоступен,
и закрывает сломанный connected socket. После перезапуска Go следующий запрос
может восстановить доставку без reload Nginx.

### P2 — тихая остановка ingest — снижено

При фатальной ошибке чтения datagram пишется сообщение в log, а `/healthz`
возвращает `503`, если ingest-loop остановился. В эксплуатации всё равно нужен
алерт по health check.

### P2 — неэффективное bounded-хранилище — исправлено в рабочем дереве

Хранилище стало ring buffer фиксированной ёмкости. Поля datagram ограничиваются
до записи в store. Для прямого HTTP действует лимит headers; в чувствительных
окружениях всё равно нужна redaction на границе отчёта.

### P2 — корректное завершение — исправлено в рабочем дереве

Процесс обрабатывает `SIGINT`/`SIGTERM`, завершает HTTP и TLS-серверы с
таймаутом, закрывает TLS listener и затем останавливает Unix socket reader.

### P2 — передача сигналов в Docker — исправлено в рабочем дереве

Entrypoint оставляет небольшой supervisor shell, чтобы завершение доходило и до
Nginx, и до Go. В образе закреплены версии Nginx и Alpine, а worker Nginx
запускается в группе `nobody`, совпадающей с защищённым socket.

### P2 — совместимость ResponseWriter — исправлено в рабочем дереве

Logging wrappers сохраняют `Flusher`, `Hijacker` и `Unwrap`, если их поддерживает
исходный writer. Текущие UI и API не используют upgrade, но middleware больше
не скрывает эти возможности без причины.
